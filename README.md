# claude15

Claude13 から、マップ（ステージ）とキャラクターの形だけを移したもの。マップは石の壁はそのままに、街に作り替えてある。

- `src/stage/Stage.js` 石の壁と海に囲まれた島（床は道路のアスファルト）
- `src/stage/City.js` 街の本体（道路・横断歩道・ビル・超高層・円筒タワー・東京タワー風の鉄塔・戸建て住宅・看板・公園・街路灯・信号・車・バス停など）
- `src/character/` ブロックキャラの形・顔・髪・関節・ポーズ（武器の形も含む）
- `src/character/Barehand.js` 素手の歩き・小走り・走り・ジャンプのモーション
- `src/character/PlayerController.js` 操作（歩く・走る・ジャンプ）。街の当たり判定と地面の高さに従う
- `src/main.js` ビューア（WASD 移動 / Shift 走る / Space ジャンプ / ドラッグで視点 / ホイールで距離 / V で街の全景）

## 縮尺

キャラの身長（約 0.74 単位）を 1.75m とみなし、**1 単位 ≒ 2.365m**。`City.js` の `m(メートル)` で実寸を単位に直している。
1 階 = 3.6m、ドア = 約 2m、道路 = 14m 幅、歩道 = 3.5m、縁石 = 15cm、車 = 4.4m、住宅 = 11m × 8.5m、鉄塔 = 150m。
実寸の街が入るよう、床は 64 → 128 に広げた（約 300m 四方）。石の壁の大きさ・積み方は元のまま。

## 配置（北が -z）

| | 西 | 中央 | 東 |
|---|---|---|---|
| 北 | 住宅地 | 超高層ビル群 | 鉄塔の広場 |
| 中 | 中層ビルの並び | **公園（戦いの広場）** | 円筒タワー + 中層ビル |
| 南 | 百貨店 + 駐車場 | 高層・ホテル・商店 | 住宅地 |

`createStage()` の返り値 `colliders` に、建物・車・噴水などの足跡 `{ minX, maxX, minZ, maxZ, height }` が入っている（将来の当たり判定用）。

## 検査（`tools/`）

ローカルサーバー（例: `python3 -m http.server 5199`）を立てて、Playwright で実行する。

- `tools/audit-overlap.cjs` 街の全ての面を調べ、同じ向き・同じ平面で重なる面（面のちらつき）を探す
- `tools/audit-collision.cjs` 約 8,000 地点にキャラ（半径 0.3）を置き、`stage.resolve()` で押し出した位置が物体の内側でないか、看板・窓の板が壁や柱に埋まっていないかを調べる

当たり判定・地面の高さ:
- `stage.solids` 触れる全ての物の当たり判定（`City.js` が見えている立体から自動で作る。箱は向きつき、円柱は円）
- `stage.resolve(x, z, r)` めり込まない位置に押し出す（壁の外にも出さない）
- `stage.groundY(x, z)` 足元の高さ（道路 0 / 歩道 0.07 / 芝 0.10 / 広場 0.14）

## 素手のモーション（`Barehand.js`）

Claude13 の `walk` / `run` / `crouch` / `air` / `land` を土台に、素手用に細かく作り直したもの。

| モーション | 内容 |
|---|---|
| `walk` | かかと着地（つま先を上げる）→ 荷重で膝が少し曲がる → 立脚中期で伸びる → つま先で蹴る。骨盤の回旋・傾き・体重移動、胸の逆ねじれ、頭は水平。腕は力を抜いて振り、手は軽く曲げる |
| `jog` | 歩きと走りの中間。加速・減速の途中で自然につながる |
| `run` | 前傾、肘約 90 度、握りこぶし、蹴った足を尻へ引きつける、両足が浮く滞空。後ろへ引く腕は肘を開く |
| `crouch` → `push` | ため（膝・腕を引く）→ 踏み切り（全身を伸ばし足首で蹴る） |
| `air` | 上昇 → 頂点 → 落下を `airU` でつなぐ。立ちは腕を振り上げ、頂点で膝を抱える。走りながらは脚を前後に開く大股 |
| `land` | 沈み込み → 立ち直り。落下が速いほど深く、走りながらは前傾のまま片足を前に着いて走りへつなぐ |

Animator に追加した値: `jumpT`（踏み切り・着地の進み）、`leadSide`（前へ出す脚）、`landK`（着地の衝撃）、手首の曲げ `lWristBend` / `rWristBend`。
速さ（リグ単位/秒）は 歩き 9.2 / 小走り 12〜 / 走り 18〜24。歩幅は移動距離に合わせるので足が滑らない。
`tools/motion-sheet.cjs` で、各モーションの位相ごとの姿勢を画像に書き出して確認できる。
